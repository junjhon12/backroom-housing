# @backroom-housing/frontend

React 19 + TypeScript + Vite client for the Backroom Housing Registry.

## Commands

```bash
npm run dev        # Vite dev server (proxies /api and /uploads to :5000)
npm run build      # Type-check and production build
npm run typecheck  # Type-check only
npm run lint       # Oxlint
npm run preview    # Preview the production build
```

See the [root README](../../README.md) for setup, demo credentials, and architecture.
